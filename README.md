# 🐾 CindyCare

Projeto de Engenharia de Software e Requisitos para organizar
os cuidados cotidianos de animais de companhia.

O nome é uma homenagem à Cindy, cachorrinha que inspirou o projeto.
Cada tutor pode cadastrar seus próprios animais.

## Objetivo

Transformar necessidades de organização em requisitos, regras de
negócio, casos de uso e critérios de aceite, acompanhados de um
protótipo navegável.

## Funcionalidades do protótipo

- Cadastro e edição de animais.
- Registro de vacinas e próximas doses informadas pelo tutor.
- Tarefas de cuidado com recorrência opcional.
- Conclusão e cancelamento de tarefas.
- Registro de consultas realizadas.
- Despesas com filtros e totalização.
- Histórico por animal.
- Armazenamento local no navegador.

## Como abrir

Baixe o projeto e abra `prototipo/index.html` em um navegador atual.
Também é possível utilizar a extensão Live Server no VS Code.

Não há dependências para instalar nem etapa de compilação.

## Tecnologias

- HTML
- CSS
- JavaScript
- LocalStorage
- Markdown e Mermaid

## Validação

Os cenários de aceitação estão documentados.
O resultado de cada cenário deve ser registrado após sua execução.

O funcionamento inicial foi conferido pela autora.
Isso não representa aprovação de todos os critérios de aceite
nem conclusão dos testes de compatibilidade e acessibilidade.

## Limitações

- Não possui login ou sincronização entre dispositivos.
- Os dados ficam no navegador e podem ser removidos ao limpar
  os dados de navegação.
- Não possui backup, recuperação de exclusões ou notificações externas.
- Não recomenda tratamentos ou calendários de vacinação.
- Utiliza dados fictícios para demonstração.
